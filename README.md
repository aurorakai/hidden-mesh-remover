# Hidden Mesh Remover

VRChat avatar tool that removes mesh hidden by "hide" blendshapes at upload. The package lives in [`Packages/com.aurorakai.hidden-mesh-remover`](Packages/com.aurorakai.hidden-mesh-remover); see its [README](Packages/com.aurorakai.hidden-mesh-remover/README.md).

Install through VCC with the listing `https://aurorakai.github.io/vpm/index.json`.
